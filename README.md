# Pure Tweaking Utility

Official Windows installers and automatic updates. This repository contains release downloads; application source code is maintained separately.

## Download v1.5 - Halloween Edition

[Download the Windows x64 installer](https://github.com/nolife67/Pure-Tweaking-Utility-Releases/releases/latest/download/PureTweakingUtilitySetup.exe)

[All releases and checksums](https://github.com/nolife67/Pure-Tweaking-Utility-Releases/releases)

The setup includes the required .NET 8 runtime. A valid Pure license is required to use the utility.

### Updating an older installation

Older versions check the previous private repository and cannot discover this release automatically. Close Pure, download the setup above and install it once. You do not need to uninstall the previous version first. Version 1.5.0 and later check this public release repository for future updates.

The release is named **v1.5**. The application, installer and release tag use **1.5.0** / **v1.5.0**, as required by the updater.
